# dotfiles

*The machines were different. The work was the same.*

There was a terminal. It was a good terminal. The type was clear and the colors were those of the desert, where the sun rose early and the shadows were long.

There was a shell. It did what was asked of it.

There was an editor. It had been around a long time. This was not a reason to replace it.

The files had traveled between machines. Some had been lost. Others had been changed by men who thought they knew better. What remained was kept here.

## The arrangement

Ghostty for the terminal.

Fish for the shell.

Vim for the words.

Solarized for the light, and for the dark.

Chezmoi to keep things in order.

Git to remember what had happened.

## On a new machine

```sh
chezmoi init https://github.com/sutrodev/dotfiles.git
chezmoi diff
chezmoi apply
```

It was best to look at the differences first. There was no shame in being careful.

## On making changes

Edit the source. Examine the difference. Apply what is good. Commit what is worth keeping.

The rest can be left behind.
